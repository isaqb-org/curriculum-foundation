# Operatorenliste für Lernziele

Die Operatoren, die in den Lernzielen dieses Lehrplans verwendet werden, basieren auf der [Operatorenliste](https://informatikstandards.de/fileadmin/GI/Projekte/Informatikstandards/Dokumente/Bildungsstandards_SII.pdf) für Didaktik in der Informatik der Gesellschaft für Informatik.

Ein Lernziel beschreibt, was Teilnehmende nach der Schulung können sollen. Der Operator im Lernziel legt fest, welche Art von Kompetenz gemeint ist – und damit auch, was Schulungen vermitteln und was in der Prüfung erwartet werden darf. So verlangt ein Lernziel „Software-Architekt:innen können … *nennen*" lediglich das Wiedergeben ohne Begründung, während „… können … *beurteilen*" bedeutet, dass Teilnehmende passende Kriterien formulieren und den Untersuchungsgegenstand anhand dieser Kriterien einschätzen können.

Lernziele sollten daher mit einem Operator formuliert werden, der die beabsichtigte Kompetenz präzise trifft. Unspezifische Formulierungen wie „kennen" oder „verstehen" beschreiben keine beobachtbare Handlung und sollten durch einen der folgenden Operatoren ersetzt werden (z. B. „kennen" → „nennen" oder „beschreiben", „verstehen" → „erklären" oder „erläutern").

| Operator | Teilnehmende können … |
|---|---|
| Analysieren | … eine Materialgrundlage untersuchen, ihre Elemente identifizieren, deren Merkmale und Beziehungen erfassen und das Ergebnis darstellen |
| Angeben, Nennen | … etwas ohne nähere Erläuterung oder Begründung wiedergeben |
| Begründen | … eine Aussage oder Entscheidung durch rational nachvollziehbare Argumente stützen |
| Berechnen | … Ergebnisse durch Rechenoperationen gewinnen |
| Beschreiben | … einen Sachverhalt unter Verwendung der Fachsprache in eigenen Worten verständlich wiedergeben |
| Bestimmen | … anhand von Kriterien einen Sachverhalt feststellen und das Ergebnis formulieren |
| Beurteilen | … unter Verwendung von Kriterien ein Sachurteil formulieren |
| Bewerten | … unter Verwendung von Kriterien ein Werturteil formulieren |
| Darstellen | … einen Sachverhalt in formalisierter Form grafisch oder fachsprachlich wiedergeben |
| Entscheiden | … anhand von zu nennenden Kriterien eine von mehreren Alternativen auswählen |
| Entwerfen | … etwas in seinen wesentlichen Zügen erstellen |
| Entwickeln | … etwas umfassend und nachvollziehbar herstellen oder konstruieren |
| Erklären | … einen Sachverhalt erfassen, in einen kausalen Zusammenhang einordnen und deuten |
| Erläutern | … einen Sachverhalt mithilfe zusätzlicher Angaben (Beispiele, Vergleiche, …) verständlich machen |
| Identifizieren | … aus einer beschriebenen Menge Elemente mit bestimmten Eigenschaften erkennen |
| Implementieren | … ein informatisches Modell auf einem oder für ein Informatiksystem umsetzen |
| Modellieren | … gemäß einer Problemanalyse ein informatisches Modell anfertigen |
| Stellung nehmen | … die eigene Meinung zu einem Problem argumentativ entwickeln und darlegen |
| Übertragen | … einen Sachverhalt in eine andere Darstellungsform bringen |
| Vergleichen | … nach vorgegebenen oder selbst gewählten Gesichtspunkten Gemeinsamkeiten und Unterschiede angeben |
| Zeichnen | … eine hinreichend exakte grafische Darstellung anfertigen |

> **Anmerkung (Korrektur gegenüber dem PDF, Version 2024.1):**
> Im Original-PDF sind die Bedeutungen von *Beurteilen* und *Bewerten* verschoben:
> *Beurteilen* trägt dort dieselbe Definition wie *Bestimmen* („anhand von Kriterien einen Sachverhalt feststellen und das Ergebnis formulieren"),
> und *Bewerten* trägt die Definition, die in der GI-Liste zu *Beurteilen* gehört („… ein Sachurteil formulieren").
> Die obige Tabelle folgt der offiziellen Operatorenliste der Gesellschaft für Informatik
> ([Bildungsstandards Informatik für die Sekundarstufe II](https://informatikstandards.de/fileadmin/GI/Projekte/Informatikstandards/Dokumente/Bildungsstandards_SII.pdf), Beilage zu LOG IN, 36. Jg. (2016), Heft 183/184, S. 14):
>
> - **Beurteilen:** unter Verwendung von Kriterien ein *Sachurteil* formulieren
> - **Bewerten:** unter Verwendung von Kriterien ein *Werturteil* formulieren
